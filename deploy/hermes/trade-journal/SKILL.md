# 交易复盘记录

## 步骤

1. 确定内容：用户这条消息里，去掉开头"记录复盘：""帮我记一下"这类指令之后的全部原话。
   只有指令、没有内容（比如只说"我要记个复盘"）时，回一句"请发内容"，用户的下一条消息就是内容。
2. 确定发送时间：内容所在那条消息开头方括号里的时间就是发送时间，如 `[Sat 2026-11-21 14:15:32 UTC]`。
   改写成 ISO 8601 带时区：`2026-11-21T14:15:32+00:00`（UTC 就是 +00:00）。消息开头没有这个时间就不填。
3. 调用 `add_journal_entry(content=原话, sent_at=发送时间)`。
4. 回复一行：`已记录（{recorded_at 的日期和时分} 纽约时间）`；返回的 `used_sent_at` 为 false 时，
   末尾加"，没拿到发送时间，用的是现在的时间"。

## 规则

- 原话照录：不改写、不纠错、不总结、不润色、不翻译，保留换行和标点；方括号里的时间戳本身不要写进内容。
- 只记录：不点评、不分析、不给建议，不调用别的工具。
- 用户一条消息里写了好几段，算一条记录。
- 调用失败就把错误原样告诉用户，不要自己换个方式写文件。
